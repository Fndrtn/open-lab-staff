# Резервное копирование данных

Программа реализует три алгоритма резервного копирования:

- **Full** — сохраняет все записи.
- **Incremental** — сохраняет новые записи с последнего полного или инкрементного копирования.
- **Differential** — сохраняет новые записи с последнего полного копирования.

Программа создаёт 200 записей и периодически выполняет резервное копирование.

Копии сохраняются в JSON:
- `folder_1` — полные.
- `folder_2` — инкрементные.
- `folder_3` — дифференциальные.

**Запуск:**
```bash
python main.py
```
