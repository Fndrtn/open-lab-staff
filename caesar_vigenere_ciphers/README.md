# Шифры Цезаря и Виженера

Простая консольная реализация шифрования и расшифрования на Python.
Программа работает со строчными русскими буквами. Введённый текст
переводится в нижний регистр, а пробелы и знаки препинания не изменяются.

## Запуск

```powershell
python main.py
```

Программа запросит исходный текст, целочисленный ключ (сдвиг) для шифра
Цезаря и буквенный ключ для шифра Виженера, после чего выведет результаты
шифрования и расшифрования обоими методами.
